# LovePlus 风格恋爱文字游戏 — 第一版试玩设计

日期：2026-11-02  
项目目录：`/workspace/loveplus-game`  
引擎：Ren'Py 8.5.3（`/home/box/tools/renpy`）

## 1. 目标

做出一个可通关的短试玩：现代校园、单女主分支视觉小说，手感接近 LovePlus 的「温柔日常对话 + 关键选择」，但不做完整日程养成。

成功标准：

- 从开场到任一结局可完整玩通
- 3 次关键选择会导向不同对话与结局
- 苏念 5 种立绘表情与至少 3 张背景可切换
- 文风为简体中文、口语自然偏甜

## 2. 范围

### 做

- Ren'Py 标准 VN：脚本、立绘、背景、选项菜单
- 1 位可攻略女主：苏念
- 固定主角名：叶辰
- 短试玩结构：认识 → 3 次关键选择 → 小结局（好感路线 / 普通朋友，由分支达成，无数值）
- AI 生成立绘与背景

### 不做（第一版）

- 多女主、完整学期/日历养成、好感条或数值
- 小游戏、语音、多语言
- 自定义主角名、CG 画廊、成就系统

## 3. 角色

### 苏念（女主）

- 身份：高一学姐，文艺社
- 气质：温柔姐姐型
- 外形：日系；棕发微卷；毛衣 + 百褶裙
- 立绘表情（5）：
  1. 默认平静
  2. 温柔微笑
  3. 略带惊讶
  4. 害羞
  5. 担心 / 轻蹙眉

### 叶辰（主角）

- 固定名字，第一人称旁白 + 对话
- 普通高中生，误入文艺社招新

## 4. 剧情骨架

钩子：社团招新日，叶辰误入文艺社摊位，认识学姐苏念。

| 节拍 | 内容 | 场景建议 |
|------|------|----------|
| 开场 | 校园招新热闹；叶辰走错摊位 | 校园走廊 / 招新广场 |
| 相遇 | 苏念温和解释文艺社；邀请帮忙或参观 | 文艺社摊位 |
| 选择① | 留下帮忙 / 婉拒先离开 | 摊位 |
| 中段 | 活动准备（海报、节目单等）中的日常对话 | 社团教室 |
| 选择② | 如何回应她的温柔关心（坦诚 / 打趣 / 逞强） | 社团教室 |
| 活动日 | 文艺社小活动当天 | 礼堂或教室布置后 |
| 选择③ | 关键表态（靠近 / 维持距离 / 含糊） | 活动后走廊或教室 |
| 结局 A | 分支走向亲近：她明确留下后日邀约感 | 放学小路 / 教室晚霞 |
| 结局 B | 分支走向普通朋友：温和收束，保留余韵 | 校门 |

分支规则：纯剧情旗标（如 `helped`、`honest`、`confess_soft`），不显示数值。三次选择的「亲近向」组合进结局 A，否则结局 B。具体旗标在实现计划里列出。

## 5. 技术架构

```
loveplus-game/
  game/
    script.rpy          # 主流程
    characters.rpy      # 角色定义
    options.rpy         # 游戏名等
    images/             # 立绘、背景
    gui/                # 默认 GUI（可用 Ren'Py 生成）
  docs/superpowers/specs/
```

- 启动与编译：`renpy /workspace/loveplus-game`
- 资源：AI 生成 PNG；立绘透明底；背景 1920×1080
- Web 导出：SDK 已含 web 支持，试玩稳定后再做

数据流：玩家选项 → 设旗标 → 条件对话 / `jump` 结局标签。无持久养成数据。

## 6. 美术清单

立绘文件建议：

- `sunian normal.png` — 默认平静
- `sunian smile.png` — 温柔微笑
- `sunian surprised.png` — 略带惊讶
- `sunian shy.png` — 害羞
- `sunian worry.png` — 担心

背景至少：

- `bg campus.png` — 招新/校园外
- `bg clubroom.png` — 社团教室
- `bg hallway.png` — 走廊（活动后）

可选第四张：`bg schoolgate.png` 用于结局 B。

生成约束：同一角色五表情脸型发型服装一致；半身或膝上立绘；无文字水印。

## 7. 文风与 UI

- 语言：简体中文
- 语气：口语自然偏甜；苏念用语柔、少命令句
- UI：Ren'Py 默认 GUI 微调即可；选项用标准 `menu`

## 8. 测试要点

- 三条「亲近」选项全选 → 结局 A
- 三条偏远选项 → 结局 B
- 混合选项按约定阈值（实现计划定为 ≥2 亲近旗标 → A）
- 五表情切换无缺图；中文无乱码
